# 验收记录

每次验收一份 Markdown，文件名 `YYYY-MM-DD-<主题>.md`。固定字段：

- **日期**
- **版本 / 提交**
- **环境**（OS、Go/Node 版本、数据目录是否隔离）
- **范围**（本次验的是哪条需求 / 哪些阶段项）
- **命令**（可复制复跑）
- **结果**（通过 / 部分通过 / 未通过）
- **证据**（测试名、输出摘要、状态码、耗时、截图路径）
- **未通过原因**（没有就写「无」；有就写清阻塞与下一步）
- **签字**（执行者；需要用户确认的写「待用户确认」）

规则：

1. 只记录实际跑过的命令与真实输出，不写计划或推测。
2. 失败照实记录，不改测试或代码去凑绿色。
3. 验收涉及真实账号/服务器时，凭据不写进记录，只写「已配置/未配置」。
